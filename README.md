# TaborPlanner

A vibe-coded planning app for summer camps designed to make reusing activities, collaboration, and daily feedback sessions *way* more efficient than Google Sheets.

## Features
- Clearly structured camp schedules grouped into program blocks and activities
- Activity database for reusing activities across multiple camps
- Custom feedback questionnaires for each camp day, plus AI summaries to speed up leaders' daily feedback sessions
- Camp schedule versioning and restoration
- Multi-user collaboration
- Automatic name day retrieval to see who is celebrating without needing to look it up manually
- Tracking for all camp leaders and their assigned groups
- Group point tracking for scored activities, making it easy to record points and freeing up the organizer's mind
